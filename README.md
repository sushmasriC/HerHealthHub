# HerHealthHub

A comprehensive women's health platform that provides educational and supportive resources across different life stages — from menstrual care to menopause.

## Overview

HerHealthHub is a web-based platform designed to empower women with knowledge and tools to manage their health throughout various life stages. The platform offers interactive features, educational videos, and personalized tracking tools for menstrual cycles, pregnancy, postpartum recovery, and menopause management.

## Features

### 🩸 Menstrual Cycle Tracking
- **Period Prediction**: Accurate predictions with symptom tracking
- **Fertility Window**: Track ovulation and fertile days
- **Health Monitoring**: Detect irregularities and manage conditions like PCOS
- **Mood Tracking**: Understand emotional patterns throughout your cycle
- **Interactive Calendar**: Visual tracking with notes and reminders
- **Hormone Dashboard**: Visualize hormone levels across cycle phases

### 🤰 Pregnancy Care
- **Trimester Tracker**: Monitor pregnancy progress week by week
- **Due Date Calculator**: Calculate estimated delivery date
- **Prenatal Guidance**: Expert advice for each trimester
- **Fetal Development**: Track baby's growth milestones
- **Health Monitoring**: Track vitals and prevent complications

### 👩‍🍼 Postpartum Care
- **Recovery Timeline**: Personalized recovery plans based on delivery type
- **Phase Tracker**: Monitor healing progress from acute to delayed phases
- **Mental Health Support**: Resources for postpartum depression awareness
- **Physical Recovery**: Exercise guidelines and pain management tips
- **Newborn Care**: Baby care essentials and feeding guidance

### 🦋 Menopause Management
- **Stage Calculator**: Identify your menopause phase
- **Symptom Tracker**: Monitor hot flashes, mood swings, and more
- **Hormone Health Chart**: Visualize estrogen and progesterone changes
- **Lifestyle Management**: Diet, exercise, and wellness tips
- **Educational Resources**: Comprehensive FAQs and video guides

### 💡 Additional Features
- **Educational Videos**: Curated video library for each health topic
- **Search Functionality**: Find relevant information quickly
- **Personalized Wellness Journey**: Customized tips based on your phase
- **Health Journey Selector**: Easy navigation through life stages
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Styling**: Custom CSS with responsive grid layouts
- **Charts**: Chart.js for hormone visualization
- **Icons**: Font Awesome 6.0
- **Storage**: LocalStorage for calendar notes and user preferences

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server setup required - runs directly in the browser

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/HerHealthHub.git
   cd HerHealthHub
   ```

2. **Open in browser**
   Simply open `index.html` in your web browser:
   ```bash
   # On Windows
   start index.html
   
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   ```

3. **Or use a local server (optional)**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js
   npx serve
   ```
   Then navigate to `http://localhost:8000`

### Usage

1. **Home Page**: Navigate through different health journey options
2. **Menstrual Tracking**: Enter your cycle details to get predictions and track symptoms
3. **Pregnancy Care**: Calculate due dates and track trimester progress
4. **Postpartum Support**: Get personalized recovery timelines
5. **Menopause Management**: Calculate your menopause stage and track symptoms
